🚀 DÉMARRAGE EN 2 MINUTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Allez sur → www.overleaf.com/login

2. Cliquez → "New Project" → "Blank Project"

3. Nommez → "Rapport_PFE_Robotique"

4. Ouvrez le fichier rapport_pfe.tex depuis votre ordinateur

5. Copiez-collez TOUT le contenu dans main.tex d'Overleaf

6. Cliquez → "Recompile" (haut droit)

7. Attendez 5-10 secondes

8. ✨ VOILÀ ! Votre PDF de 20+ pages s'affiche

Table des matières vide ?
→ Compilez deux fois (LaTeX doit générer les indexes)

Caractères mal affichés ?
→ Vérifiez que l'encodage UTF-8 est présent (\usepackage[utf-8]{inputenc})

Package not found ?
→ Tous les packages sont standards sur Overleaf, pas de problème prévu

Le PDF ne se génère pas ?
→ Cliquez "Clear cached files" dans le menu (trois points)
→ Réessayez la compilation
